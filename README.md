# sudyke/homebrew-tap

Homebrew tap for my macOS apps.

## Install

```bash
brew tap sudyke/tap
brew install --cask claudia
```

Or as a one-liner:

```bash
brew install --cask sudyke/tap/claudia
```

## Casks

| Cask | Description |
|---|---|
| [`claudia`](Casks/claudia.rb) | Menu bar app that monitors Docker, Supabase, and a local dev server. [Source](https://github.com/sudyke/Claudia) |
